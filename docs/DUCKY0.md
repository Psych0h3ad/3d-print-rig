# Ducky0 source parts

Six public printed attachments from [Ducky28/Ducky0](https://github.com/Ducky28/Ducky0/tree/a831046bed5624bc98ab2a42843d2d5ae851755a) are available as independent source-part previews. This is not a complete Ducky0 printer or a verified installation on the stock V0.2r1.

Source revision: `a831046bed5624bc98ab2a42843d2d5ae851755a`, 2024-11-14. The repository supplies seven STL files and no native printer assembly or occurrence transforms for these attachments. The [source receipt](../site/DUCKY0_SOURCES.json) pins all acquired bytes, Git identities and included/withheld files.

Original nonzero triangles, winding and print coordinates are retained. Conversion changes millimetres to metres, coordinate axes, unit face normals and the viewer base material. STL has no authored base/accent colors. Built-in supports have not been identified or removed. Source identities drive selection and recoloring; purchased hardware and speculative assembly transforms are not added. The [exporter](../scripts/convert_ducky0_sources.py) rejects unpinned, nonfinite and degenerate inputs.

The repository declares GPL-3.0; every payload contains the upstream license and a source/change notice. Ducky's README credits [Fizzy / @FizzysTech's FT BTT Pi TFT70 screen mount](https://www.printables.com/model/581227-ft-btt-pi-tft70-screen-mount), currently CC-BY-SA-4.0. That original attribution and license are retained separately. [Creative Commons lists GPLv3 as a one-way compatible adaptation license](https://creativecommons.org/compatible-licenses/); this does not relicense the original work. Only Ducky's attachment STL is included, not Fizzy's complete screen enclosure or frame brackets. Its exact original revision, inherited geometry and preferred modification source are not established by the pinned Ducky tree.

The bottom panel is withheld: Ducky identifies it as a remix of [Cthulhu's printed bottom panel](https://www.printables.com/model/467247-voron-02-printed-bottom-panel), whose primary page declares CC-BY-NC-4.0. No alternate GPL grant was established. Its mesh is absent from public payloads; the source receipt records the reason.

The linked Double Shear AB STEP has genuine upstream occurrence transforms, but no Ducky cooling brackets. Deconstruder has genuine upstream toolhead CAD but no explicit reuse grant in its inspected public tree. Neither establishes a complete Ducky0 assembly or installation of these attachments. Hardware completeness, mating features, fan/nozzle/probe positions, support isolation, installed motion and continuous clearance remain open. README speed, acceleration, heat and flow claims are not simulator limits.

Automated checks distinguish source/fixture coverage, actual exported mesh fidelity, all-machine exported attributes and browser review from native-solid installation certification. Model and adapter hashes and the current inspection scope are recorded in the release evidence. No full-machine or installed-combination certification is implied.
