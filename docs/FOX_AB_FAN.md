# Trident A/B motor fans

FOX V1 is available for Trident350 with the standard R2 gantry, Stealthburner, CW2 and Revo Voron. Select it in the printer’s additional parts. V1 and V2 are alternatives; selecting one replaces the other. Changing the head or gantry can remove an incompatible selection, and a notice asks you to check the companion parts. Saved configurations with an unsupported V1 combination are rejected.

The V1 preview includes two printed brackets and 26 unchanged Voron reference hardware parts. The local bracket mounting surfaces and seam triangles are reconstructed from the original public 3MF for web display, with a measured source deviation below 0.008 mm. The original source, hardware, holes, seats and poses are preserved. No built-in supports were removed; eight exactly zero-area source draw triangles are omitted. This is a selected geometry preview, not a test of cooling performance, wiring or whole-printer operation.

The selected source attachment is recorded in [the installation record](FOX_AB_FAN_SELECTED_INSTALLATION.json). The release checks the actual exported 28-part model, its closed oriented surfaces, normals and original hardware against [the source witnesses](FOX_AB_FAN_SOURCE_WITNESSES_V30.json). Other sizes, heads, boards and changer modes are not registered for V1.
