GPL-3.0 applies; attribution and remix credits are retained in `site/licenses/stealth_skirts/`.

Select a standard VORON Trident, then choose a style under Additional Mods. Selecting one replaces the other. Disabling it restores the stock assembly. Configuration JSON retains the style. Base/accent controls color native prints; hardware keeps its materials. The original assembly supplies feet, four fans, PiTFT50 V2.1 and the filtered inlet. Current author STLs supply the panels and their native holes; original editable CAD supplies remaining components. Invalid older CAD panels are replaced by current STL surfaces. No integrated print supports are removed.

Rigid registration retains native dimensions. The greatest median STL/CAD difference is about 0.118 mm, reflecting the author’s updated STL versus older CAD. The native frame-contact plane sets the height. Stock skirt hardware is hidden together with its body. Native VORON M3 slot nuts align to actual source screw axes: 20 for 250 mm, 24 each for 300 / 350 mm. All skirt parts remain fixed through bed motion.

The source archive supplies preferred original editable CAD, STLs, source hashes, registered metadata, analytic common parts, slot nuts and checks. Embedded hardware retains separate terms.
