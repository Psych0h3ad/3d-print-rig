# 3D Print Rig

[日本語](https://psych0h3ad.github.io/3d-print-rig/viewer/?lang=ja) · [English](https://psych0h3ad.github.io/3d-print-rig/viewer/?lang=en) · [License](LICENSE) · [Third-party notices](docs/THIRD_PARTY_NOTICES.md)

組立済みSTEP：標準VORON V2.4 R2・Trident R2の250 / 300 / 350 mm、Micron R1 120・Micron Plus R1 180。[ビューアーの「標準STEP」からダウンロード](https://psych0h3ad.github.io/3d-print-rig/viewer/?lang=ja)。

[E3NG交換機構の参考CAD](https://psych0h3ad.github.io/3d-print-rig/viewer/e3ng.html?lang=ja)：公開されているホットエンド交換機構・ドック・専用ガントリーを表示。EBB36 / 42、押出機の軸とアーム、1〜6ツールを選択できます。機体全体の組立CAD・可動検証は含みません。
